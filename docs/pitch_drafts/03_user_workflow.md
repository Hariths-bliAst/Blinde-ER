## Zero-Button, Voice-First Gesture Flow
1. **Launch & Audio Greeting:** App announces readiness via TalkBack/VoiceOver and haptic pulse.
2. **Single Tap Anywhere:** Captures the book page image using the native document camera.
3. **Auditory Progress Feedback:** Haptic + spoken status updates while CRNN extracts text and the LLM refines/translates the narrative.
4. **Automatic Audiobook Playback:** Native TTS narrates the contextualized passage; **Double Tap anywhere** pauses/resumes; **Long Press anywhere** switches target language or repeats the passage.
