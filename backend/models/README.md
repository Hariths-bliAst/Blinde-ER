# Custom CRNN Model Weights Folder (For Hariths)

Drop your trained CRNN model file into this folder (`backend/models/`):
- Example PyTorch weights: `backend/models/crnn_book_scanner.pth`
- Example ONNX weights: `backend/models/crnn_book_scanner.onnx`
- Example Keras/TensorFlow weights: `backend/models/crnn_book_scanner.h5`

*(Note: All `.pth`, `.pt`, `.onnx`, and `.h5` files are automatically ignored by `.gitignore` so large model binaries won't break GitHub pushes.)*
